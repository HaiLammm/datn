# Story 8.3: Báo cáo Đánh giá Hiệu suất Phỏng vấn (Interview Performance Report)

Status: ready-for-dev

## Story

As a người tìm việc (Job Seeker),
I want để nhận báo cáo đánh giá chi tiết về hiệu suất của mình sau buổi phỏng vấn,
So that tôi có thể học hỏi từ những sai lầm và cải thiện kỹ năng phỏng vấn của mình.

## Acceptance Criteria

1. **Given** tôi đã hoàn thành một buổi phỏng vấn ảo, **When** tôi truy cập báo cáo đánh giá, **Then** tôi thấy điểm tổng thể, điểm mạnh, điểm yếu và gợi ý cải thiện cụ thể. (Covers FR16)
2. **Given** tôi xem lại báo cáo, **When** tôi nhấp vào một câu hỏi cụ thể, **Then** tôi có thể xem lại câu hỏi và câu trả lời của mình (văn bản và âm thanh nếu có).
3. **And** báo cáo được lưu trữ an toàn và chỉ tôi mới có thể truy cập.

### Database Schema - interview_evaluations Table

```sql
CREATE TABLE IF NOT EXISTS interview_evaluations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    interview_id UUID NOT NULL,
    
    -- Overall Evaluation
    final_score DECIMAL(3,1) NOT NULL CHECK (final_score >= 0 AND final_score <= 10),
    grade VARCHAR(5) NOT NULL,
    hiring_recommendation VARCHAR(20) NOT NULL 
        CHECK (hiring_recommendation IN ('Strong Hire', 'Hire', 'Consider', 'No Hire')),
    
    -- Dimension Scores (stored as JSONB for flexibility)
    dimension_scores JSONB NOT NULL,
    
    -- Detailed Analysis
    detailed_analysis JSONB NOT NULL,
    
    -- Recommendations
    recommendations JSONB NOT NULL,
    
    -- Metadata
    evaluated_at TIMESTAMP WITHOUT TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    agent_model_used VARCHAR(100) DEFAULT 'Llama-3.2-3B-Instruct',
    evaluation_duration_seconds INTEGER,
    
    -- Foreign key
    CONSTRAINT fk_interview
        FOREIGN KEY (interview_id)
        REFERENCES interview_sessions (id)
        ON DELETE CASCADE,
    
    -- Ensure one evaluation per interview
    CONSTRAINT unique_interview_evaluation UNIQUE (interview_id)
);

CREATE INDEX IF NOT EXISTS idx_interview_evaluations_interview_id 
    ON interview_evaluations (interview_id);
```
